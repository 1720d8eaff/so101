# 展示材料清单

| 放什么 | 建议位置 | 内容要求 |
| --- | --- | --- |
| 硬件与相机布局 | `docs/media/` | 真实照片与简短标注，不出现无关私人信息 |
| 任务说明 | `docs/tasks.md` | 操作对象、初始条件、自然语言指令与成功判定 |
| 运行配置 | `configs/` | 脱敏配置；替换机器路径、账号和设备标识 |
| 短演示视频 | README 中的视频链接 | 固定任务成功、代表性失败、扰动恢复各一段；标记模型版本 |
| 评测表 | `docs/results.md` | 成功次数 / 总次数、测试条件、检查点、种子、失败分类 |
| 数据说明 | `docs/data.md` | 来源、采集方式、单位、相机键、划分和过滤规则 |
| 运行日志 | 按需脱敏后添加 | 实际时间、命令与检查点版本，不能只放截图中的单个最好结果 |

原始数据、视频和权重默认被 `.gitignore` 排除，避免误提交大文件。需要公开视频时可用 GitHub 附件或单独媒体托管，并在 README 加可访问链接。准备公开报告时附对应配置与版本；未跑出的结果留空，不预填简历里的数字。
